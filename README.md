# 🐾 Pet Services Appointment Booking System

A full-stack web application built with PHP and MySQL that allows users to book appointments for various pet-related services such as grooming, veterinary checkups, and training. The project follows the MVC (Model-View-Controller) architecture for better code organization and scalability.

## 🚀 Features

- 🐶 Book appointments for different pet services
- 📅 View available time slots
- 🔐 Basic user authentication (login/register)
- 🧾 Admin dashboard to manage services and appointments
- 📁 Organized using the MVC design pattern
- 💾 Database managed with phpMyAdmin (MySQL)

## 🛠️ Technologies Used

- **PHP**
- **MySQL** (via phpMyAdmin)
- **HTML/CSS**
- **MVC Architecture**
